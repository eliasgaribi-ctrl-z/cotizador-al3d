Muestras de UI · parte 5: la plataforma, el taller y el anidador

Once piezas: moverse entre pantallas, las fechas del taller, el mapa, el dinero que ya se debe y la mesa de corte. Todo se puede tocar con el dedo, el ratón o el teclado.

46 · Buscar un proyecto desde cualquier pantalla

Vengeance · Search Modal

Toca la lupa o aprieta / fuera de un campo. Escribe «farm», «0042» o «guadalupe» (sin acento también sirve). Flechas para moverte, Enter para abrir, Esc para cerrar. La lista espera 220 ms a que dejes de teclear.

47 · «Más» en la barra de abajo del teléfono

Vengeance · Awwwards Nav

Toca «Más» o sube la barra con el dedo (desde cualquiera de sus botones). Si la sueltas antes de un tercio, regresa. Cada módulo trae su globo; «Más» suma los suyos. Para cerrar: el velo, Esc o jalar la hoja hacia abajo.
